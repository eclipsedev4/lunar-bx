# Lunar BX

A Lunar Client-style launcher for Roblox, written in Rust.

## Run
1. Install Rust: https://rustup.rs
2. In this folder, run:

    cargo run --release

Roblox must be installed and signed in. The first build takes a few minutes.

Linux only: you may need `sudo apt install libxkbcommon-dev libwayland-dev libgl1-mesa-dev` first.
